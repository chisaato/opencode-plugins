# @misakacloud/opencode-compact-enhance

OpenCode V2 插件：在 OpenChamber Web 或 TUI 触发上下文压缩时，指定摘要应优先保留哪些细节、略去哪些内容。需要 OpenCode 2.3.2 或更高版本。

## 安装

在 OpenCode 的 `opencode.jsonc` 中添加插件：

```jsonc
{
  "plugins": ["@misakacloud/opencode-compact-enhance@latest"]
}
```

## 用法

在 OpenChamber Web 或 TUI 的会话输入框中，从斜杠菜单选择 `/compact-enhance`，并按需附上指令：

```text
/compact-enhance 保留关键架构决策、失败原因和未解决问题；略去重复的调试日志
```

不带参数或参数只有空白时，等同于普通 `/compact`，不会设置摘要指令。压缩请求失败时（例如会话内容太少，无法压缩），客户端会显示命令错误。

## 工作原理

插件在服务端注册命令，因此 OpenChamber Web 和 TUI 都能在斜杠菜单中找到它。服务端保存指令（如有）后，请求压缩当前会话。压缩钩子将指令附加到发给摘要模型的请求中，不会把它写进聊天记录。摘要模型会被要求在保留默认摘要格式的同时，优先按指令调整内容取舍和细节密度。

- 指令按会话保存，**只在下一次进入压缩钩子时生效一次**。同一会话再次设置指令会覆盖尚未使用的旧指令。
- 如果会话内容太少或其他原因让这次请求还没进入压缩钩子，指令会保留到下一次压缩；无论是手动 `/compact` 还是自动压缩，都能使用它。
- 指令在压缩钩子中取出后即被消费。如果后续摘要生成失败，需重新提交指令。未使用的指令仅保存在服务端内存中，不会跨重启保留。
