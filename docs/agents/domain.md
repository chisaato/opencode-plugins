# 领域文档

本仓库采用 single-context 布局：根目录 `GLOSSARY.md` 记录术语，`docs/adr/` 记录架构决策。

## 探索前读取

- 读取根目录 `GLOSSARY.md`。
- 读取 `docs/adr/` 下与当前工作相关的 ADR。
- 文件或目录不存在时，静默继续，不将缺失报告为问题，也不预先创建空文件。术语或决策确定后再通过 `/domain-modeling` 按需记录。

## 使用已有术语

Issue 标题、重构提案、假设和测试名涉及领域概念时，沿用 `GLOSSARY.md` 的定义，不使用其中明确排除的同义词。

尚未收录的概念，先确认是否引入了项目不使用的说法；确有术语缺口时，留待 `/domain-modeling` 处理。

## 显式指出 ADR 冲突

提案与已有 ADR 冲突时，注明具体 ADR 及重新讨论的理由，不默默覆盖已有决策。
